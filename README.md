# Moon Cycle

A Flutter app for Android and iOS that follows the lunar cycle: today's
phase, the exact dates and times of new, quarter and full moons, and
moonrise and moonset for where you are. Everything is computed on the
device, so it works offline.

## Getting started

```sh
flutter pub get
flutter test
flutter run
```

Requires Flutter 3.47 or later. Building for iOS needs a Mac with Xcode, or
a cloud build service such as Codemagic.

## Project layout

```
lib/
  main.dart                 entry point
  app.dart                  MaterialApp: theme, locales, home
  core/
    astronomy/              the moon engine (pure Dart, no Flutter imports)
    theme/                  colours, typography, the dark theme
  features/
    home/                   home screen (placeholder until Phase 2)
  l10n/                     English and French strings (ARB) and generated code
assets/fonts/               Cormorant Garamond and Inter, bundled (SIL OFL)
test/
  astronomy/                engine tests against published data
```

## The moon engine

`MoonCalculator` in `lib/core/astronomy` is the only entry point the app
needs:

```dart
const calc = MoonCalculator();
final state = calc.stateAt(DateTime.now(), location: here);
state.phaseName;            // MoonPhaseName.waxingGibbous
state.illuminatedFraction;  // 0.0 to 1.0
state.age;                  // time since the last new moon
calc.nextPhase(DateTime.now(), phase: PrincipalPhase.fullMoon);
calc.phasesBetween(start, end);
calc.riseSet(year: 2026, month: 10, day: 21, location: here, utcOffset: offset);
```

It implements Jean Meeus, *Astronomical Algorithms* (2nd ed., 1998):

| What | Method | Accuracy |
| --- | --- | --- |
| Moon position | ch. 47, truncated ELP-2000/82 | ~10″ |
| Sun position | ch. 25, low accuracy | ~0.01° |
| Illumination, bright limb | ch. 48 | < 0.1% |
| New, quarter and full moon times | ch. 49 | seconds |
| Moonrise and moonset | altitude search with h0 = 0.7275π − 34′ | < 1 min |

The tests check it against the worked examples in Meeus, the NASA and USNO
phase tables, and moonrise and moonset times from PyEphem for Kinshasa,
Paris, New York, Sydney and Tromsø.

## Translations

Strings live in `lib/l10n/app_en.arb` (the template) and `app_fr.arb`. The
Dart code next to them is generated by `flutter gen-l10n`, which also runs
on `flutter pub get` and `flutter run`.
